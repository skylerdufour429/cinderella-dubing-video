# Cinderella Dub Collection

A GitHub Pages + GitHub Codespaces-ready web application for organizing
multiple language MP4 versions of **Cinderella (1950)**.

## Movie Information

- **Movie:** Cinderella
- **Year:** 1950
- **Studio:** Walt Disney Productions
- **Category:** Animated Feature

## Features

- HTML5 video player
- Language selector
- 44 language entries
- MP4 open buttons
- MP4 download buttons
- Language search
- Responsive mobile layout
- GitHub Pages compatible
- GitHub Codespaces compatible
- No build system required

## Project Structure

```text
cinderella-dub-collection/
├── index.html
├── styles.css
├── app.js
├── README.md
└── media/
    ├── cinderella-1950-albanian.mp4
    ├── cinderella-1950-arabic.mp4
    ├── cinderella-1950-bengali.mp4
    ├── ...
    └── cinderella-1950-vietnamese.mp4
````

## GitHub Codespaces

Open the repository in GitHub Codespaces.

No Node.js installation or build command is required.

The application is static HTML, CSS, and JavaScript.

## GitHub Pages

In the repository:

1. Open **Settings**.
2. Select **Pages**.
3. Select **Deploy from a branch**.
4. Select the repository's main branch.
5. Select `/root` as the folder.
6. Save the configuration.

The site will then be available at:

```text
https://YOUR-USERNAME.github.io/cinderella-dub-collection/
```

## Media Files

The application expects the MP4 files in:

```text
/media/
```

with filenames following this pattern:

```text
cinderella-1950-LANGUAGE.mp4
```

Example:

```text
cinderella-1950-japanese.mp4
```
