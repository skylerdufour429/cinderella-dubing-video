# Cinderella Dub Collection

A static GitHub Pages-ready movie dub collection web app.

## Movie

- Movie: Cinderella
- Year: 1950
- Studio: Walt Disney Productions
- Category: Animated Feature
- Languages: 45

## Features

- HTML5 MP4 video player
- 45 language entries
- Play button for every language
- MP4 download links
- Language search
- Language dropdown
- Responsive mobile layout
- No backend
- GitHub Pages compatible
- GitHub Codespaces compatible

## Run locally

Open `index.html` in a browser.

Or use a local development server:

```bash
python3 -m http.server 8000
