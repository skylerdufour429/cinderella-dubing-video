## GitHub Pages Setup

1. Upload project to GitHub.
2. Open:

Settings → Pages

3. Select:

Deploy from branch

4. Choose:

main branch / root folder

5. Save.


## GitHub Codespaces

Open:

Code → Codespaces → Create codespace

Run locally:

python -m http.server 8000

Open the forwarded port.
